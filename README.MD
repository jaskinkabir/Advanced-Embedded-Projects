This repo holds the project files for my Advanced Embedded Systems class at UNC Charlotte. I took this class in Fall 2025. The class explored advanced bare-metal programming and embedded systems architecture on the STM32-based Nucleo-F091RC Development Board. 

Each folder, which you can reach through the hyperlinks below, contains a README.md file that describes the project in more detail and provides a demonstration video.

# Projects
## [Project 1: Stack Frame Analysis](./cube/stackframedebug)
Intro to STM Cube IDE, the memory viewer, and function stack frames.
## [Project 2: GPIO and External Interrupts](./cube/interrupt_project)
GPIO configuration, external interrupts, debouncing, and PWM signal generation.
## [Project 3: SPI LCD Control](./cube/spi_lcd)
Interfacing with an LCD over SPI. Displays a picture of Walter White from Breaking Bad.
## [Project 4: PWM LED Control](./cube/pwm_led)
Uses the timer peripheral to control the brightness of an LED.
## [Project 5: Minimal Bootloader](./cube/Minimal_Bootloader)
Explores memory partitioning, vector tables, and boot-time control transfer
